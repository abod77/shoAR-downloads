# shoAR


Silent Hill: Origins Arabic Installer


تعريب وتطوير: **aBo_SaaD_B52**


[تحميل shoAR.exe مباشرة](https://github.com/abod77/shoAR-downloads/releases/download/shoARv1.0/shoAR.exe) · [صفحة التنزيلات](https://github.com/abod77/shoAR-downloads/releases/tag/shoARv1.0)


1. حمّل shoAR.exe وافتحه مباشرة.
2. انتظر اكتشاف اللعبة والمحاكي، ثم اختر التثبيت الموصى به.
3. شغّل اللعبة واختر «العربية» مع علم السعودية.


إذا لم تُكتشف اللعبة أو المحاكي، استخدم «اختيار يدوي».


Windows 10/11 x64. يعمل دون إنترنت. تحتاج إلى نسختك الأصلية المدعومة من اللعبة. لا يحتوي التنزيل على اللعبة أو ISO أو BIOS أو المحاكي. يتوفر ZIP كخيار بديل في صفحة التنزيلات.


هذا المستودع مخصص لتنزيل التطبيق فقط، ولا يتضمن السورس.
